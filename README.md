# Aggie Bookstore Management System

A Python-based bookstore management system developed through multiple stages as I learned and applied new programming concepts.

## About the Project

The Aggie Bookstore Management System is a command-line Python application for organizing and displaying bookstore inventory. The project was developed incrementally, with each version introducing new programming concepts and improving the structure of the application.

## Project Development

### Version 1
- Created the initial bookstore inventory program.
- Collected inventory counts for different book genres.
- Used conditional statements to determine which genres were available.

### Version 2
- Introduced loops and nested data structures.
- Stored book titles based on genre.
- Used dictionaries and lists to organize bookstore inventory.
- Displayed available titles for each genre.

### Version 3
- Added functions to organize the program.
- Read book genres from a text file.
- Read inventory information from a CSV file.
- Created a menu for selecting genres.
- Calculated and displayed inventory totals and prices.

### Version 4
- Introduced object-oriented programming.
- Created and imported `Book` and `Author` classes.
- Converted CSV inventory data into Book and Author objects.
- Organized books by genre using dictionaries and lists.
- Calculated total inventory quantity and value for selected genres.
